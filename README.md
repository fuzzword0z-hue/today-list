# 오늘

혼자 쓰는 가벼운 "오늘 할 일" 체크리스트 + 캘린더(공적·사적·케어 일정) + 주·월·년 통계 + 월간·연간 리포트.
서버·계정·동기화 없이 휴대폰 안에만 저장되고, 홈 화면에 설치하면 앱처럼 오프라인으로 동작합니다.

- 설계 문서(경쟁 앱 분석, UX/UI 설계): [DESIGN.md](DESIGN.md)

## 사용법

| 동작 | 방법 |
|---|---|
| 추가 | 아래 입력창에 적고 엔터 (연달아 입력 가능) |
| 완료 / 취소 | 할 일을 탭 |
| 수정 | 길게 누르기 (PC: 더블클릭) — 내용을 다 지우면 삭제 |
| 삭제 | 왼쪽으로 밀기 → 실행 취소 가능 (실행 취소는 그 변경만 되돌리고, 그 사이 체크하거나 새로 적은 것은 그대로) |
| 내일로 미루기 | 오른쪽으로 밀기 |
| 못 끝낸 일 | 상단 배너의 "오늘로 가져오기" (지난 7일분) |
| 다른 날 | 상단 ‹ › |
| 일정 추가 | 캘린더 탭 → 날짜 선택 → 오른쪽 위 ＋ (분류: 공적 · 사적 · 케어, 반복: 매일·이틀마다·매주·매달 등). 케어는 **투약·처치 / 병원** 중 선택, 병원은 지난 진료 기준 4주·5주 후 날짜 버튼 |
| 일정 수정·삭제 | 일정을 탭 → 시트에서 수정 / 일정 삭제 (반복 일정은 "이 날만 · 이 날부터 · 모두" 선택) |
| 투약·진료 체크 | 케어 일정 오른쪽 원을 탭 (오늘 화면, 캘린더 케어 카드, 선택한 날 목록 어디서든). 일정을 열면 그 날 기록을 **했어요/못 했어요/기록 없음**(병원은 다녀왔어요/안 갔어요)으로 바꿀 수 있음 |
| 체크 누락 확인 | 어제~3일 전 케어 체크가 비어 있으면 오늘 화면 위에서 "했어요 / 못 했어요"를 물어봄. 2개 이상이면 한 줄로 묶이고, 펼쳐서 하나씩 또는 **n개 모두 했어요** |
| 고양이 컨디션 | 오늘 화면의 '고양이 컨디션' 카드를 눌러 식욕·활력·구토·배변을 고르고 체중·메모 입력 (한 번 더 누르면 지워짐). **치아 이 닦이기**는 카드를 펼치지 않아도 바로 체크 |
| 운동 | 하단 **운동** 탭: 등 운동·어깨 교정(12회 × 3세트), 플랭크(한 칸 30초, 최대 3분), 사이드 플랭크(한 칸 10회, 최대 60회). 칸을 누르면 그 칸까지 채워지고 마지막 칸을 다시 누르면 하나 빠짐. 아래 **전체 지우기** / **오늘 운동 완료** (완료 기록은 월간·연간 리포트에만 반영) |
| 출근일 · 쉬는 날 | 날은 **출근일 / 쉬는 날**로 나눔 (박물관 근무: 토·일도 번갈아 출근). 기본 쉬는 날은 **매주 월요일**. 스케줄 휴무·연차·공휴일 다음 날 휴관은 캘린더의 **쉬는 날 고르기**(근무표 · 연차)에서 날짜를 눌러 바꾸고, 그날 바로는 운동·공부 탭 위 [출근일 / 쉬는 날]로. 쉬는 날은 달력에 '휴', 오늘 화면에 '· 쉬는 날' |
| 쉬는 날·그 밖의 운동 | 쉬는 날엔 운동 탭 맨 위 **쉬는 날 운동**에 [시작~끝 시간 + 내용] (예: 점심 먹고 걷기, 하루 두어 번도). 출근일엔 **그 밖의 운동**(접힘)에 퇴근 후 걷기 등. 시간은 자동 합계, 쓰면 한 줄씩 늘어남. 적은 날은 '운동한 날'로 셈 |
| 식후 스쿼트 | 운동 탭 (출근일·쉬는 날 모두, 출근일은 '점심 먹고'): 한 칸 10회, 목표만큼 칸 (처음 50회 = 5칸, 아래 −/+로 10회씩 바꿔 100회까지). 리포트 운동 칸·건강 칸에 '식후 스쿼트 n일 · 평균 n회' |
| 지난 날 기록 | 운동·공부 탭 맨 위 **기록 날짜**에서 지난 날을 고르면 그 날 기록을 새로 쓰거나 고침 (예: 완료를 깜빡한 날 → 날짜 고르고 체크 → **10/13 운동 완료**). **오늘로**로 돌아옴. 전날 체크가 남은 채 다음 날 열면 [그 날로 기록하고 새로 시작 / 지우기 / 오늘 것으로 이어서] 중에 고르기 |
| 8:30–9:30 루틴 | 운동 탭 맨 위 (출근일만, 토·일 출근일 포함): 20분 운동 · 집안일 · 샤워 체크. 20분 운동은 **기본 / 생리 기간 / 실내자전거** 중 골라서 목록과 진행 칸(기본 1·2·3바퀴, 생리 기간 1·2바퀴·마무리, 자전거 5·10·15·20분)을 채움. 칸을 다 채우면 20분 운동 자동 체크, 고른 버전은 체크를 지워도 유지 |
| 공부 | 하단 **공부** 탭: 출근일·쉬는 날 모두 [시작~끝 시간 + 내용] 줄 (네 줄부터, 다 쓰면 한 줄씩 늘어남). 출근일도 같은 방식 (계획 버튼 없음 — 퇴근 후 1차 7:00–8:30 · 2차 9:30–11:00 공부를 지켰는지는 리포트에서 봄). 끝이 시작보다 한참 이르면(오전·오후를 잘못 고름) 줄 아래에 경고 — 자정을 넘긴 6시간 이내 줄(23:30–0:40)은 그대로 셈. 아침 복습 체크, 캘린더의 공적 일정 D-day 표시. 쉬는 날로 바꾸면 운동 탭의 8:30–9:30 루틴도 숨겨짐. **전체 지우기** / **오늘 공부 완료** (기록은 리포트에만) |
| 내 건강 | 오늘 화면의 '내 건강' 카드: **안 지킨 것만** 누름 (아무것도 안 누른 날 = 다 지킨 날). 과자 먹음(이유: 스트레스·피곤·지루함·배고픔·기타. 기타를 고르면 상황을 직접 적는 칸이 나옴) · 주의 음식 먹음(빵·라면·김밥·튀김) · 야채 먼저 안 먹음 · 늦게 잠(11:30 넘어 잔 날. 이유는 여러 개: 일·집안일·고양이 케어·핸드폰·잠이 안 옴. 고양이 케어를 고르면 **오심 지켜봄 / 구토 후 확인**도 고름 — 아픈 고양이를 지켜본 밤은 늦게 잠 주 목표에서 빼고 따로 세며, 진료 전 요약에 '밤에 지켜본 날'로 들어감. 다음 날 아침엔 '어젯밤'으로, 밤 10시 넘어서는 자기 전에 '오늘 밤'으로 체크 → 잔 날 밤으로 기록). 위에 **이번 주 예외 횟수 / 목표**와 주의 음식 **D+n** (14일에 한 번). 카드를 펼치면 체중(잴 수 있는 날만), 진료 검사 수치, 주 목표 바꾸기 |
| 진료 수치 | '내 건강' 카드 펼치기 → **진료 수치 적기**: 진료일 · 당화혈색소 · 총콜레스테롤 · LDL · HDL · 중성지방 · 메모 (받은 것만). 다음 진료는 4개월 뒤로 잡히고(바꿀 수 있음) D-day 표시, 지나면 카드 머리에 '진료 수치 적기'. 최근 3번 진료를 표로 비교, 날짜를 누르면 고치기·지우기 |
| 감사일기 | 하단 **일기** 탭: 하루 한 장, 한 줄에 하나씩 감사한 일 (20줄 기준으로 줄 수 표시, 넘어도 저장). 쓰면 바로 저장, ‹ ›로 지난 날도 쓰고 고침. 아래 달력에 쓴 날 표시, **이번 달 일기 모아 보기**, **이번 달 일기 복사 (피드백용)** → 채팅에 붙여 넣기. 리포트엔 쓴 날·줄 수만 (내용은 넣지 않음) |
| 지우기 전 확인 | 운동·공부 탭에서 아직 완료로 기록하지 않은 내용을 지우려 하면 "기록하고 지우기 / 기록하지 않고 지우기"를 물어봄 |
| 진료 전 요약 | 캘린더 케어 카드 → 진료 전 요약 보기: 지난 진료 이후 투약·컨디션·체중·메모 정리, 텍스트 복사 |
| 통계 | 하단 통계 탭 → 주 / 월 / 년 |
| 리포트 | 새 달 1–7일에 앱을 열면 지난달 리포트 도착 (1월엔 연간 리포트도). 지난 리포트는 통계 → 월/년 → 리포트 보기 |
| 백업 | 통계 탭 맨 아래 (저장 공간 사용량도 표시 — 휴대폰 브라우저 한도 약 5MB) → **내보내기**: 기록 전체를 `today-backup-날짜.json` 파일로 저장 (휴대폰에 저장 또는 드라이브·카톡 등으로 보내기) / **불러오기**: 그 파일을 골라 기록을 되살림 (지금 기록을 바꾸기 전에 확인, 실행 취소 가능). 불러오기 직전 기록을 한 벌 따로 두어서, 나중에라도 **'M/D 불러오기 전 기록으로 되돌리기'**로 되살릴 수 있음. 모양이 이상한 항목은 빼고 불러오고, 화면이 멈추면 원래 기록으로 돌아감 |
| 하루의 시작 | 새벽 4시. 자정을 넘겨 체크·기록해도 그날로 남음 (예: 새벽 1시 = 아직 어제) |
| 반복 | 매일 · 이틀마다 · 3일마다 · 매주 · 2주마다 · 매달 · **매년** (생일 등, 2월 29일은 평년엔 28일) |
| 문제가 생기면 | 화면을 그리다 오류가 나면 '기록 내보내기 / 다시 열기' 안전 화면이 뜸 (기록은 그대로) |

## 휴대폰에 설치하기

정적 파일만 있으므로 HTTPS로 올리기만 하면 됩니다. (서비스 워커는 HTTPS에서만 동작)

### 1) 웹에 올리기 — GitHub Pages
1. 저장소 **Settings → Pages → Build and deployment**에서 Source: `Deploy from a branch` 선택
2. Branch: 이 코드가 있는 브랜치(`main`으로 병합했다면 `main`) / `/ (root)` 선택 후 Save.
3. 1–2분 뒤 `https://<GitHub 아이디>.github.io/today-list/` 주소가 생깁니다.

> 비공개 저장소는 GitHub 유료 플랜에서만 Pages를 쓸 수 있습니다. 공개 저장소로 해도 **할 일 내용은 휴대폰 안에만 저장**되므로 코드 외에는 아무것도 공개되지 않습니다.
> 대안: [Netlify Drop](https://app.netlify.com/drop)이나 Cloudflare Pages에 폴더를 그대로 끌어다 놓아도 됩니다.

### 2) 홈 화면에 추가
- **iPhone (Safari):** 주소 열기 → 공유 버튼 → **홈 화면에 추가**
- **Android (Chrome):** 주소 열기 → ⋮ 메뉴 → **앱 설치** (또는 홈 화면에 추가)

설치 후에는 인터넷이 없어도 열립니다.

> ⚠️ 기록은 설치한 그 앱 안에만 저장됩니다. 브라우저의 '쿠키 및 사이트 데이터' 삭제·앱 삭제 시 함께 지워집니다. 가끔 **통계 → 백업 → 내보내기**로 파일을 만들어 두세요.
> iPhone에서는 Safari 탭이 아니라 **홈 화면 아이콘으로 열어서** 사용하세요 (둘의 저장소가 서로 다릅니다).

## 코드를 고친 뒤 배포할 때

`sw.js`의 `VERSION`과 `index.html`의 `?v=` 값을 **같은 숫자로 함께 올리세요** (예: `3` → `4`).

- 설치된 앱은 새 버전의 파일을 **전부 받아 둔 다음** 한 번에 바꿔서, 새 HTML과 옛 CSS가 섞이는 일이 없습니다.
- 받아 온 `index.html`에 새 `?v=`가 없으면(서버가 아직 옛 파일을 줄 때) 그 버전은 설치하지 않고 다음에 다시 시도합니다.
- 열려 있는 앱을 바로 새로 고치지 않습니다. 앱이 화면에서 내려갔을 때(다른 앱으로 가거나 화면을 끔) 새로 고치고, 시트나 입력 칸을 쓰는 중이면 그다음으로 미룹니다.
- 버전을 올리지 않으면 설치된 앱은 계속 예전 버전으로 열립니다.
