# 오늘

혼자 쓰는 가벼운 "오늘 할 일" 체크리스트 + 캘린더(공적·사적·케어 일정) + 주·월·년 통계 + 월간·연간 리포트.
서버·계정·동기화 없이 휴대폰 안에만 저장되고, 홈 화면에 설치하면 앱처럼 오프라인으로 동작합니다.

- 설계 문서(경쟁 앱 분석, UX/UI 설계): [DESIGN.md](DESIGN.md)

## 사용법

| 동작 | 방법 |
|---|---|
| 추가 | 아래 입력창에 적고 엔터 (연달아 입력 가능) |
| 완료 / 취소 | 할 일을 탭 |
| 수정 | 길게 누르기 (PC: 더블클릭) — 내용을 다 지우면 삭제 |
| 삭제 | 왼쪽으로 밀기 → 실행 취소 가능 (실행 취소는 그 변경만 되돌리고, 그 사이 체크하거나 새로 적은 것은 그대로) |
| 내일로 미루기 | 오른쪽으로 밀기 |
| 못 끝낸 일 | 상단 배너의 "오늘로 가져오기" (지난 7일분) |
| 다른 날 | 상단 ‹ › |
| 일정 추가 | 캘린더 탭 → 날짜 선택 → 오른쪽 위 ＋ (분류: 공적 · 사적 · 케어, 반복: 매일·이틀마다·매주·매달 등). 여행처럼 **여러 날** 이어지는 일정은 '까지 → 여러 날이면 고르기'로 끝나는 날을 정함 (공적 · 사적, 반복 없는 일정) — 달력에서는 이름 하나인 한 줄 막대로 이어지고, 그 날 목록 · 오늘 화면에는 'n/m일'로 며칠째인지 표시. 케어는 **투약·처치 / 병원** 중 선택, 병원은 지난 진료 기준 4주·5주 후 날짜 버튼 |
| 일정 수정·삭제 | 일정을 탭 → 시트에서 수정 / 일정 삭제 (반복 일정은 "이 날만 · 이 날부터 · 모두" 선택) |
| 투약·진료 체크 | 케어 일정 오른쪽 원을 탭 (오늘 화면, 캘린더 케어 카드, 선택한 날 목록 어디서든). 일정을 열면 그 날 기록을 **했어요/못 했어요/기록 없음**(병원은 다녀왔어요/안 갔어요)으로 바꿀 수 있음 |
| 체크 누락 확인 | 어제~3일 전 케어 체크가 비어 있으면 오늘 화면 위에서 "했어요 / 못 했어요"를 물어봄. 2개 이상이면 한 줄로 묶이고, 펼쳐서 하나씩 또는 **n개 모두 했어요** |
| 고양이 컨디션 | 오늘 화면의 '고양이 컨디션' 카드를 눌러 식욕·활력·배변을 고르고 체중·메모 입력 (한 번 더 누르면 지워짐). **구토는 한 번에 한 줄**: [+ 거품] [+ 사료] [+ 위액] [+ 헤어볼] [+ 약 직후] [+ 기타]를 누를 때마다 1회(오늘이면 지금 시각), 줄을 누르면 종류·시각·**피 섞임**·메모 고치기·지우기, 토하지 않은 날은 '안 토함'. 피 섞임·약 직후면 안내 문구, 진료 전 요약에 날짜·시각·종류와 시간대 패턴. **밤에 지켜봄**(오심 지켜봄 · 구토 후 확인)은 진료 전 요약에 '밤에 지켜본 날'로. **치아 이 닦이기**는 카드를 펼치지 않아도 바로 체크 |
| 오늘 한 것 | 오늘 화면의 **오늘 한 것** 한 줄: [운동] [공부] [명상] (+ '고치기'로 산책 등 더하기, 최대 6개). 누르면 '했어요' — 시간·양·기준은 묻지 않음 (5분도, 단어 10개도). 위에 '이번 주 운동 2일 · 공부 3일'처럼 **한 날만** 셈 (못 한 날·연속 기록 없음). 지난 날은 ‹ ›로 가서 체크. 예전 운동·공부 탭 기록은 '한 날'로 옮겨져 있음 |
| 명상 1분 | '오늘 한 것'의 명상 아래 **[☀ 일어나서] [☾ 자기 전]** — 침대에서 하루 두 번 1분. 누르면 어두운 화면의 타이머(원이 4초 커지고 6초 작아짐, 들이쉬고·내쉬고, 화면 꺼짐 방지), 1분이 지나면 진동과 함께 기록 → [1분 더] [마치기]. 15초 넘게 했으면 중간에 그만둬도 기록. 아침·밤 시간대엔 그 버튼이 강조됨 (알림은 휴대폰 알람으로) |
| 출근일 · 쉬는 날 | 기본 쉬는 날은 **매주 월요일** (박물관 근무: 토·일도 번갈아 출근). 스케줄 휴무·연차·공휴일 다음 날 휴관은 캘린더의 **쉬는 날 고르기**(근무표 · 연차)에서 날짜를 눌러 바꿈. 쉬는 날은 달력에 '휴', 오늘 화면에 '· 쉬는 날' |
| 내 건강 기록 | **통계 탭 → 내 건강 기록**: 체중(잴 수 있는 날에만, 날짜 골라 적기 · 추세 그래프)과 진료 검사 수치(당화혈색소 · 콜레스테롤 · 중성지방, 지난 진료 대비 변화, 다음 진료 D-day). 오늘 화면에는 진료 7일 전부터 '수치 적기' 알림만. 매일 누르던 '안 지킨 것' 체크와 주 목표는 없앰 (예전 기록은 백업에 남음) |
| 일기 | 하단 **일기** 탭, 하루 한 장: 맨 위 **나침반**(지향하는 문장, 고치기·접기) → **오늘 해낸 것**(한 줄만 보이고 [+ 한 줄 더], 앱 기록에서 꺼낸 끝낸 일·오늘 한 것·케어 칩을 누르면 줄에 들어감) → **감사일기**(한 줄이면 충분, 줄 수만 표시) → **마음에 이름 붙이기**(여러 개, 직접 더하기, 무거운 마음이면 '나에게 한마디' 칸) → **더 쓰고 싶을 때**(접힘: 오늘의 질문 · 나를 채우는 시간 · 흔들린 순간). 점수·연속 기록 없음. 쓰면 바로 저장, ‹ ›로 지난 날도 쓰고 고침. 달력에 쓴 날 표시, **이번 달 일기 모아 보기**, **이번 달 일기 복사 (피드백용)** → 채팅에 붙여 넣기 |
| 진료 전 요약 | 캘린더 케어 카드 → 진료 전 요약 보기: 지난 진료 이후 투약·컨디션·체중·메모 정리, 텍스트 복사 |
| 가계부 | **통계 탭 위 [기록] [가계부]** 중 오른쪽. 매일 쓰지 않고 **급여일(25일, 주말 · 성탄절이면 앞 평일)에 한 번** 적는 표: 들어온 돈(급여 · 상여금+기타 수당) · 나간 돈(월세+관리비+보험+디딤씨앗(기부) · 핸드폰+인터넷+가스비 · 가족여행비(모임비) · 카드값) · 모은 돈(IRP · ISA · 연금저축펀드 · 청약 · 비상금(찡찡이 병원비)) → **남은 돈** 자동 계산 (모자란 달은 **'비상금에서 채웠어요'** 한 번 누르면 꺼낸 돈으로 적고 남은 돈에 더함). 금액이 정해진 항목은 '매달 같은 돈'으로 자동 채움. **모아 둔 돈**(통장 잔액: IRP · ISA · 펀드 · 청약 · 비상금, 생각날 때 적고 안 적은 달은 마지막 금액), **다음 급여일까지 쓸 돈 계획**(식비 · 고양이 간식·캔 · 가족·친구 · 고양이 병원비) — 이미 산 것은 ○를 눌러 **'샀어요'**로 체크하면 '샀어요 n · 앞으로 쓸 돈 n · 할부 n'으로 나눠 보임, 다음 달에 실제 카드값과 나란히, **할부**(최대 5개월, 카드값에 들어 있는 몫을 보여 주고 '한꺼번에 갚았어요'), 이번 달 메모, **흐름**(최근 6달 카드값 · 모은 돈 · 남은 돈 · 비상금, 올해 모은 돈). 항목은 '항목 고치기'에서 바꿈. 급여일부터 오늘 화면에 '급여일 가계부' 배너 (그 달 들어온 돈을 적으면 사라짐) |
| 통계 | 하단 통계 탭 → [기록] → 주 / 월 / 년: 끝낸 일 · 오늘 한 것을 한 날 카드, **습관 트래커**(습관마다 한 줄 — 주·월은 날마다 한 칸, 한 날만 채움, 명상은 위 반 아침·아래 반 밤 / 년은 달마다 한 날 수, 자주 할수록 진하게, 누르면 그 달로) + 자주 한 요일·가장 많이 한 달, 아래에 **고양이 체중**(마지막 체중 · 지난번과 처음 기록 대비 kg · %, 그래프, 기록 목록, 날짜 골라 적기 · 지우기 — 오늘 화면 고양이 컨디션의 체중과 같은 기록)과 **내 건강 기록**. 완료율 · 연속 기록은 보여 주지 않음 |
| 리포트 | 새 달 1–7일에 앱을 열면 지난달 리포트 도착 (1월엔 연간 리포트도). **해낸 것만** 셈: 끝낸 일 · 오늘 한 것 · 투약 · 일기 · 해낸 것, **해낸 것 모아 보기**(날마다 끝낸 일 · 한 것 · 적은 줄), 고양이 · 건강 · 마음, 잘하고 있는 점 · 응원 · '다음 달에 가볍게 해 볼 것'(두 개까지). 점수·등급·고칠 점·목표 제안 없음. 지난 리포트는 통계 → 월/년 → 리포트 보기 |
| 백업 | 통계 탭 맨 아래 (저장 공간 사용량도 표시 — 휴대폰 브라우저 한도 약 5MB) → **내보내기**: 기록 전체를 `today-backup-날짜.json` 파일로 저장 (휴대폰에 저장 또는 드라이브·카톡 등으로 보내기) / **불러오기**: 그 파일을 골라 기록을 되살림 (지금 기록을 바꾸기 전에 확인, 실행 취소 가능). 불러오기 직전 기록을 한 벌 따로 두어서, 나중에라도 **'M/D 불러오기 전 기록으로 되돌리기'**로 되살릴 수 있음. 모양이 이상한 항목은 빼고 불러오고, 화면이 멈추면 원래 기록으로 돌아감 |
| 하루의 시작 | 새벽 4시. 자정을 넘겨 체크·기록해도 그날로 남음 (예: 새벽 1시 = 아직 어제) |
| 반복 | 매일 · 이틀마다 · 3일마다 · 매주 · 2주마다 · 매달 · **매년** (생일 등, 2월 29일은 평년엔 28일) |
| 문제가 생기면 | 화면을 그리다 오류가 나면 '기록 내보내기 / 다시 열기' 안전 화면이 뜸 (기록은 그대로) |

## 휴대폰에 설치하기

정적 파일만 있으므로 HTTPS로 올리기만 하면 됩니다. (서비스 워커는 HTTPS에서만 동작)

### 1) 웹에 올리기 — GitHub Pages
1. 저장소 **Settings → Pages → Build and deployment**에서 Source: `Deploy from a branch` 선택
2. Branch: 이 코드가 있는 브랜치(`main`으로 병합했다면 `main`) / `/ (root)` 선택 후 Save.
3. 1–2분 뒤 `https://<GitHub 아이디>.github.io/today-list/` 주소가 생깁니다.

> 비공개 저장소는 GitHub 유료 플랜에서만 Pages를 쓸 수 있습니다. 공개 저장소로 해도 **할 일 내용은 휴대폰 안에만 저장**되므로 코드 외에는 아무것도 공개되지 않습니다.
> 대안: [Netlify Drop](https://app.netlify.com/drop)이나 Cloudflare Pages에 폴더를 그대로 끌어다 놓아도 됩니다.

### 2) 홈 화면에 추가
- **iPhone (Safari):** 주소 열기 → 공유 버튼 → **홈 화면에 추가**
- **Android (Chrome):** 주소 열기 → ⋮ 메뉴 → **앱 설치** (또는 홈 화면에 추가)

설치 후에는 인터넷이 없어도 열립니다.

> ⚠️ 기록은 설치한 그 앱 안에만 저장됩니다. 브라우저의 '쿠키 및 사이트 데이터' 삭제·앱 삭제 시 함께 지워집니다. 가끔 **통계 → 백업 → 내보내기**로 파일을 만들어 두세요.
> iPhone에서는 Safari 탭이 아니라 **홈 화면 아이콘으로 열어서** 사용하세요 (둘의 저장소가 서로 다릅니다).

## 코드를 고친 뒤 배포할 때

`sw.js`의 `VERSION`과 `index.html`의 `?v=` 값을 **같은 숫자로 함께 올리세요** (예: `3` → `4`).

- 설치된 앱은 새 버전의 파일을 **전부 받아 둔 다음** 한 번에 바꿔서, 새 HTML과 옛 CSS가 섞이는 일이 없습니다.
- 받아 온 `index.html`에 새 `?v=`가 없으면(서버가 아직 옛 파일을 줄 때) 그 버전은 설치하지 않고 다음에 다시 시도합니다.
- 열려 있는 앱을 바로 새로 고치지 않습니다. 앱이 화면에서 내려갔을 때(다른 앱으로 가거나 화면을 끔) 새로 고치고, 시트나 입력 칸을 쓰는 중이면 그다음으로 미룹니다.
- 버전을 올리지 않으면 설치된 앱은 계속 예전 버전으로 열립니다.
